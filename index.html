Projects

Text to image ai site:

This project is a text-to-image AI platform that transforms user prompts into custom visuals using cutting-edge image generation APIs. The modern React.js frontend—styled with Tailwind CSS and enhanced with JavaScript, Axios, and React Toastify—offers a responsive, intuitive interface. On the backend, a robust Node.js/Express setup (integrated with cors, helmet, morgan, and rate limiting) handles API communications with services like Stability AI, OpenAI DALL-E, Hugging Face, Replicate, DeepInfra, and Craiyon. Deployed using Docker, Netlify, and Railway/Koyeb with Git version control, this project showcases a seamless blend of full-stack development and DevOps practices.
